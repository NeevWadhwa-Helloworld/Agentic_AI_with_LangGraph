# CampusQuery AI - Intelligent Agentic College Assistant

CampusQuery AI is an intelligent, agentic college assistant designed to streamline student access to complex institutional data. Built as a hands-on exploration into Agentic AI architectures, the application utilizes an advanced Retrieval-Augmented Generation (RAG) pipeline to accurately parse and answer natural language student queries regarding institutional fee structures and student manuals.

Unlike traditional linear RAG pipelines, this project leverages an **agentic workflow** to dynamically evaluate user intent, intelligently route queries, and handle multi-step reasoning to deliver context-aware, reliable answers.

## 🛠️ Tech Stack

* **Language:** Python
* **Agentic Framework:** LangGraph (for multi-step reasoning, intent routing, and state management)
* **LLM & RAG Orchestration:** LangChain
* **Frontend/UI:** Streamlit

## ✨ Key Features

* **Intent Evaluation & Query Routing:** Dynamically analyzes student queries to determine the best path for retrieving accurate answers.
* **Multi-Step Reasoning:** Moves beyond simple vector searches to handle complex, multi-part institutional questions.
* **Institutional Knowledge Base:** Optimized for parsing dense academic documents, student manuals, and complex fee structures.
* **Interactive UI:** A clean, easy-to-use conversational interface built with Streamlit.
